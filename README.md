Framework: Next.js 16.3.0
UI: React 19
Language: TypeScript
CSS: Tailwind CSS v4
Icons: lucide-react
Architecture: Next.js App Router + React Server Components
Purpose: A responsive landing page recreated from a Figma design.
No backend/database is required for the basic website.

The project keeps website content in JSON files and passes that content into reusable components.

How to run it
Open PowerShell inside the project folder — the folder containing package.json.
Run:
npm install
and
npm run dev
